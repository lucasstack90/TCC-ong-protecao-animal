# Sistema de Gestão para ONGs de Proteção Animal

## 📋 Sobre o Projeto
O **Sistema de Gestão para ONGs de Proteção Animal** é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do Curso Técnico em Desenvolvimento de Sistemas.

O sistema tem como objetivo facilitar a administração de ONGs e grupos independentes de proteção animal por meio da centralização das informações em uma única plataforma. A proposta busca reduzir o uso de planilhas e registros manuais, tornando o gerenciamento mais eficiente, organizado e seguro.

## 🎯 Objetivo
Desenvolver uma aplicação web que permita o gerenciamento das principais atividades realizadas por organizações de proteção animal, oferecendo maior controle sobre os dados e auxiliando na tomada de decisões.

## ⚙️ Funcionalidades

### 🐶 Gestão de Animais
* Cadastro de animais resgatados
* Edição e exclusão de registros
* Histórico de resgates
* Controle do status do animal
* Informações sobre saúde e descrição

### 🤝 Gestão de Voluntários
* Cadastro de voluntários
* Controle de participação
* Consulta de informações

### 🏠 Adoção
* Cadastro de adoções
* Histórico de adoções realizadas
* Controle de animais disponíveis

### 💰 Doações
* Registro de doações
* Histórico de doadores
* Acompanhamento das contribuições

### 📊 Dashboard
* Quantidade de animais cadastrados
* Animais disponíveis para adoção
* Total de voluntários
* Total de adoções
* Indicadores gerais do sistema

## ⚠️ Problema
Grande parte das ONGs e grupos independentes de proteção animal ainda realiza o controle de informações utilizando planilhas, documentos físicos ou anotações, dificultando o gerenciamento dos dados, aumentando a possibilidade de erros e reduzindo a eficiência das atividades.

## 💡 Solução
Desenvolver uma plataforma web centralizada que permita o gerenciamento de animais, voluntários, adoções e doações em um único ambiente, facilitando a organização das informações e contribuindo para uma gestão mais eficiente.
